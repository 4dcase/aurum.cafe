# aurum.cafe
A premium, single-page editorial website for AURUM, a luxury café concept focusing on "golden moments" and craft coffee. Built with semantic HTML5, custom CSS3 variables, and vanilla JavaScript, the site features a dynamic searchable menu, smooth GSAP animations, and an interactive gallery. The project is designed as a frontend-only application with no backend dependencies, utilizing a consolidated architecture for seamless deployment. Key highlights include responsive mobile navigation, a custom lightbox, and a warm, gold-accented design system inspired by high-end magazine layouts.
